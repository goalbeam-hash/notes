Дальше main.py создаёт главное окно Tkinter (root = tk.Tk()), задаёт заголовок «Git Autosync & Version Restore», размер окна и сразу скрывает его (root.withdraw()), чтобы оно не мелькало пустым.

Потом идёт попытка импорта класса GitVersionRestoreApp из gui.py. Если импорт провалился (например, ошибка внутри gui.py или файл отсутствует), то GUI считается недоступным и приложение работает без интерфейса. Если импорт прошёл — создаётся объект app = GitVersionRestoreApp(root), окно показывается (root.deiconify()), и к крестику закрытия окна привязывается метод app.on_closing (чтобы при закрытии окна корректно остановить watcher и observer).

После этого (или параллельно, если GUI не удалось) запускается фоновая задача — threading.Thread с target=start_observation из main_func.py. Это запускает настоящий watchdog.Observer, который следит за папкой WATCHED_FOLDER (C:\Users\f\OneDrive\autosync). Observer использует класс ChangeHandler из main_func.py. Когда происходит любое событие с файлом (создание, изменение, удаление), ChangeHandler проверяет, не игнорируется ли путь (по IGNORED_DIRS из config), и если нет — вызывает schedule_push().

schedule_push() — это функция из main_func.py. Она отменяет предыдущий таймер (если был), создаёт новый Timer на DEBOUNCE_SECONDS (обычно 10 секунд) и в качестве callback ставит do_push из do_push.py. То есть после любого изменения файла ждём 10 секунд тишины, и только потом запускаем do_push.

do_push — это сердце всей логики. Она защищена глобальным push_lock (чтобы не запускалась параллельно). Внутри do_push происходит следующее:

1. sync_files_to_fake() — копирует все файлы из WATCHED_FOLDER в FAKE_PUSH_GIT, обновляет более новые, а удалённые перемещает в DELETED_TEMP.
2. ensure_fake_repo_initialized() — если .git нет — создаёт репозиторий, добавляет remote origin, делает initial commit если HEAD unborn.
3. clean_fake_git_temp_if_needed(repo) — пытается очистить индекс (index.clear + add_all), если не получается — полностью сбрасывает папку FAKE_PUSH_GIT через safe_reset_folder и пересоздаёт repo.
4. Гарантирует, что HEAD на main (set_head или checkout).
5. stage_all_safe(repo) — git add .
6. has_changes(repo) — проверяет статус, если изменений нет — пропуск.
7. Если изменения есть — создаёт коммит с сообщением AutoSync + timestamp, вызывает generate_commit_description (из gen_description.py) для красивого описания.
8. save_push_comment — сохраняет сообщение коммита в PUSH_COMMENTS_DIR/<sha>.txt.
9. safe_push_with_auth(repo) — самая сложная часть:
    - credentials_cb — возвращает UserPass с твоим токеном
    - fetch origin
    - если origin/main нет — прямой push
    - если есть — merge_analysis:
        - UP_TO_DATE → обычный push
        - FASTFORWARD → merge + push
        - иначе (конфликт/non-ff) → вызывает handle_conflict_force_push (из conflict.py, если есть), а потом force-push с +refspec
10. finally — очищает DELETED_TEMP, снимает push_lock, вызывает parser_logger() и run_logger_clean() для очистки логов.

Если в safe_push_with_auth возникает конфликт (merge_analysis не UP_TO_DATE и не FASTFORWARD), то вызывается handle_conflict_force_push(repo). Эта функция должна (ты её пока не показал полностью, но предполагается):

- пытаться rebase на origin/main
- если rebase падает — создавать новую ветку conflict-<timestamp>
- копировать текущие файлы в папку Versions/Conflict-<timestamp>
- пушить новую ветку
- возвращаться на main
- делать force-push в main

После успешного force-push в main изменения из локального fake_git_temp попадают на GitHub, даже если были конфликты.

    - start_background_watcher() → если gui_watcher есть, запускает его
    - Создаёт GUI (GitVersionRestoreApp) → root.mainloop()
    - main_loop_cycle() — бесконечный цикл в фоне
3. **main_func.py** (самая важная часть)
    - ChangeHandler ловит событие → schedule_push()
    - schedule_push() → Timer(DEBOUNCE_SECONDS, do_push) → через 10 сек вызывает do_push()
4. **do_push.py** — самая сложная логика
    - sync_files_to_fake() → копирует файлы из OneDrive в fake_git_temp
    - ensure_fake_repo_initialized() → создаёт repo если нет, добавляет origin
    - clean_fake_git_temp_if_needed() → очищает индекс или сбрасывает папку
    - stage_all_safe() → git add .
    - has_changes() → проверка
    - commit() → git commit
    - generate_commit_description() → описание
    - save_push_comment() → сохраняет в push_comments/<sha>.txt
    - safe_push_with_auth() → fetch → merge анализ → push / force-push
